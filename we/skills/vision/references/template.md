# PRD template

The file is `docs/plans/<vision>/PRD.md`, one per product. Each section is one or two sentences when
the PRD is sharp; a multi-page PRD is a fuzzy one.

```markdown
---
type: vision
vision: <product-slug>
created: YYYY-MM-DD
updated: YYYY-MM-DD
status: living
---

# Product Vision — <product name>

## Why this product exists

<One paragraph, plain language, multi-year horizon.>

## Who this is for

<One named audience: role, situation, what they care about.>

## What is broken today

<The problem in the audience's words. No solution language.>

## What changes when this works

<The after picture: what the audience can do that they could not before.>

## What we are NOT building

<Explicit non-bets and why. This section keeps the Sagas honest.>

## Bets and assumptions

<The few beliefs the PRD rests on, each falsifiable. If one is wrong, the PRD shifts.>
```
