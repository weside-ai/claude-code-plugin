# we

The plugin root. Authoring contract: [AUTHORING.md](AUTHORING.md). User docs: [../README.md](../README.md).

Run a working copy instead of the installed plugin: `claude --plugin-dir <path>/we --settings '{"enabledPlugins":{"we@weside-ai":false}}'`;
an interactive session reloads the `/flow` hooks module when a file under `hooks/flow/` changes.
