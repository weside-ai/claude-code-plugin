we — Agentic Product Ownership for Claude Code

Plan at four altitudes, build with one Lead, deliver one PR. You review and merge.

1 · Plan

/we:visionthe PRD: audience, problem, intended change, non-bets
/we:sagaa theme that serves the vision
/we:epica bounded initiative with named stories
/we:storyone sprint-sized story with a build-ready plan

/we:meet <altitude> decomposes an artifact one altitude down, with a council of role lenses (/we:council) when you want one. /we:grill stress-tests a plan one question at a time.

2 · Build

/we:orchestrate is the Lead. It refines a story without a plan (/we:refine), dispatches one dev worker per approved plan (/we:develop, in its own worktree), checks the report against the acceptance criteria and the DoD, pushes once, opens one PR and runs /we:ci-review when CI concludes.

3 · Deliver

You review and merge. /we:merged removes the worktrees and branches and moves the tickets to Done.

The effort rule

  • The default worker is we:dev-medium: Opus at effort medium.
  • we:dev-high for promises across several code paths, money, transactions or idempotency, fragile paths, a second attempt, and plan-writing.
  • Implementation never runs on Sonnet. One implementer per story; parallel only for disjoint files.

The measurements: we/AUTHORING.md.

/plugin marketplace add weside-ai/claude-code-plugin
